# ✅ Cursor To-Do List App

A simple, responsive To-Do List web application built with **HTML, CSS, JavaScript, and Cursor AI**. It helps users organize daily tasks with an intuitive interface and saves tasks locally in the browser.

## ✨ Features

- **Add Tasks:** Quickly add new tasks to your list.
- **Complete Tasks:** Mark tasks as completed when finished.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Filters:** View all, active, or completed tasks.
- **Local Storage:** Tasks remain saved after refreshing the browser.
- **Task Statistics:** Track total tasks and completed tasks.
- **Responsive Design:** Use the app on desktop and mobile screens.
- **Input Validation:** Handle empty task submissions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage
- Cursor AI

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No backend server, database, or API key is required.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/cursor-todo-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd cursor-todo-app
   ```

3. Open `index.html` in your browser.

You can also open the folder in Cursor and use its preview or a local development extension.

## 💡 How to Use

1. Open the application in your browser.
2. Enter a task in the input field.
3. Add the task to your list.
4. Mark tasks as completed when you finish them.
5. Use the filters to view all, active, or completed tasks.
6. Delete tasks when they are no longer needed.
7. Refresh the page to verify that your tasks are saved.
